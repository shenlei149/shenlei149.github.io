### 数学笔记的排版与公式格式

本规范仅约定 Markdown 排版和公式写法，不规定翻译或讲解的内容与行文风格。

#### 段落与标题

1. 正文的每个自然段占一段源文件文本；段落之间留一个空行。不要使用两个以上的连续空行，也不要用行尾两个空格或 `<br>` 强制换行。
2. 页面正文不写 `#` 或 `##` 标题，小节统一以 `### 标题` 划分。页面开头直接从引言正文或首个 `### 标题` 开始。标题上下各留一个空行，标题文字简洁，不加句号。
3. 在正文中，中文与阿拉伯数字、英文术语、行内代码、行内公式之间各留一个半角空格。例如：`在 15.1 小节`、`函数 $f$ 在曲线 $C$ 上`、`流量（`flow`）`。
4. 标点紧贴其前后的中文或行内公式，不额外插入空格。例如：`公式 $(2)$。`、`当 $t=0$ 时`、`区间 $[a,b]$ 内`。
5. 公式内部不为排版额外加入空格；变量、运算符、积分微分和范围保持紧凑，例如 `$a\leq t\leq b$`、`$\int_a^b f(x)dx$`。
6. 行内公式只用于短的符号、变量、坐标、区间、公式编号和简短关系；使用单个 `$` 包裹，不在 `$` 内加入前后空格。

#### 定义、定理与步骤框

1. 定义、定理、推论、公式汇总、测试和“如何求……”等独立知识块，先写加粗标题，下一行立刻开始引用块；标题和引用块之间不留空行。

```markdown
**定理 1 - 名称**
> 条件与结论。
> $$\int_C fds=\cdots\tag{1}$$
```

2. 引用块的每一行，包括段落、列表、公式和空行，均以 `>` 开头。块内公式写为 `> $$...$$`，不脱离引用块。
3. 定理按 `**定理 n - 名称**` 或 `**定理 n 名称**` 格式；无编号的定义、推论、公式、测试和方法直接使用 `**名称**`。加粗标题中允许包含行内公式，如 `**求 $\boldsymbol{F}=M\boldsymbol{i}+N\boldsymbol{j}+P\boldsymbol{k}$ 的线积分**`、`**$z=f(x,y)$ 曲面面积公式**`。
4. 引用块中的步骤用 `> 1.`、`> 2.` 等 Markdown 有序列表；各步骤的配套公式另起引用行。
5. 例题、解答和证明使用普通正文行，不使用引用块：
   - 例题以 `例 n` 开头（“例”与阿拉伯数字之间留一个半角空格，如 `例 1`、`例 2`）；
   - 例题题干独立成段。题干与后续的解答（`解：`）、证明（`证明：`）、插图或子问编号（如 `（1）`、`（a）`）之间留一个空行（回车换段），严禁依赖行尾双空格换行；
   - 解答和证明分别以 `解：`、`证明：` 开头（中文冒号紧贴），各子问及其解答亦各占独立自然段，段落之间留一个空行；
   - 若例题包含多个子问，在题目与解答中采用全角编号 `（a）`、`（b）` 或 `（1）`、`（2）` 标明，各子问独立成段。

#### 块级公式

1. 独立公式使用 `$$...$$`，单独占行：
   - 当公式紧承上文引导词（如“那么”、“因此”、“有”、“解：”、“如下”等）时，紧接下一行书写，无需额外空行；
   - 多个紧密相关的独立公式（如并列定义式、连续两项结果）可连续占行书写，之间不留空行；
   - 当公式作为段落结语后接全新自然段时，公式块与后续段落之间留一个空行。
2. 短公式、定义式和单步等式在同一行写完，不为形式统一而拆行。

```markdown
$$\nabla\cdot\boldsymbol{F}=0$$
```

3. 只有连续推导、并列计算或公式确实过长时才使用 `aligned`；等号用 `&=` 对齐，每一步用 `\\` 换行。

```markdown
$$\begin{aligned}
\int_C\boldsymbol{F}\cdot d\boldsymbol{r}&=\int_a^b\boldsymbol{F}(\boldsymbol{r}(t))\cdot\boldsymbol{r}'(t)dt\\
&=f(B)-f(A)
\end{aligned}$$
```

4. 并列定义或条件需要分行时，也用 `aligned`，在行首用 `&` 对齐或将对应的等号 `&=` 对齐；需要在行末补充换元或条件时，使用 `&&` 右对齐（例如 `&=\int... &&w=1+\sin^2 u\\`）。
5. 需要在正文中交叉引用的核心公式以 `\tag{n}` 编号；正文中的引用写作 `公式 $(n)$`。普通计算过程不编号。
6. 分式、根号、上下限、求和、积分和微分均使用 LaTeX 语法；不以纯文本近似数学符号或运算。
7. 向量、单位基向量、法向量及零向量等粗体数学对象统一使用 `\boldsymbol{...}`，例如 `\boldsymbol{F}`、`\boldsymbol{i}`、`\boldsymbol{j}`、`\boldsymbol{k}`、`\boldsymbol{n}`、`\boldsymbol{T}`、`\boldsymbol{0}`。
8. 常用微积分与场论算子规范：
   - 旋度与散度：使用 `\text{curl }\boldsymbol{F}`（或 `\nabla\times\boldsymbol{F}`）与 `\text{div }\boldsymbol{F}`（或 `\nabla\cdot\boldsymbol{F}`），注意使用 `\text{div }` 避免 LaTeX 默认 `\div` 渲染为除号 $\div$；
   - 积分符号：闭合曲线积分统一使用 `\oint_C`，曲面积分使用 `\iint_S`，三重立体积分使用 `\iiint_D`；
   - 微分微元保持紧凑（如 `ds`、`dxdy`、`d\sigma`、`dV`、`d\boldsymbol{r}`），微分符号使用常规 `d`，前面不加 `\,` 薄空格。
9. 定界符与矩阵结构：
   - 叉积、旋度等行列式使用 `\begin{vmatrix} ... \end{vmatrix}`，列之间使用双 `&&` 作为间隔符；
   - 定积分求值上下限统一使用 `\bigg[ ... \bigg]_a^b` 或 `\bigg|_a^b`；含分式的高公式外层括号使用 `\bigg(...)`，普通括号不额外放大。

#### 图像、表格与列表

1. 图片使用无标题的相对路径写法 `![](文件名.png)`，独立成段，前后各留一个空行。图片命名统一遵循 `小节号.序号.png`（如 `010.010.png`、`040.020.png`）。
2. 表格只用于并列比较的数据；分隔行使用紧凑写法 `|--|--|`，数学内容写在单元格内的 `$...$` 中。
3. 普通枚举采用 Markdown 有序列表；同一题的并列情形采用全角编号“（1）”“（2）”或“（a）”“（b）”。
4. 中英文混排的术语首次或重点出现时，将英文放入反引号中，并以中文全角圆括号紧贴中文包裹，例如 `路径无关（`path independence`）`、`矢量场（`vector field`）`。括号与中文间不留空格。
